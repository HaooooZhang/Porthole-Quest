输入格式与统计口径

A -> B -> C 表示依赖链。
A,B -> C,D 表示每个前置分别连接每个后续。
单写 Solo 添加孤立任务。
external: X,Y 标为章节外节点，只保留直接邻居。
focus: C 以 C 为起始位置；不写则从章节根部进入。
# 后是注释。名称不含空格。

红圈：不同连线的中心线相交或接触，共同节点端口除外。黄圈：两条边共用一段线，每对边计一次（包含正常分叉共线）。穿节点：路径进入非端点节点内部。忽略线宽及箭头面积，统计不代表严格图论交叉数。
